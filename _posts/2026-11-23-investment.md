## 一、财报阅读要点

### 审查意见

- 标准无保留
- 附带说明无保留
- 保留意见
- 无法出定意见
- 否定意见

### 重点关注

1. 管理层讨论与分析（公司业务介绍）
2. 股份变动及股东情况（公司股份结构）
3. 财务报告（三大表）

## 二、三大表及其勾稽关系

| 表 | 类比 | 特点 |
| :-: | :-: | :-: |
| 资产负债表 | 骨骼，公司基本面 | 瞬时拍照，定位某一时刻的资产状态 |
| 利润表 | 肌肉，可以show，可能不真实 | 区间，定位季度/半年/年度内的盈利变化 |
| 现金流量表 | 血液，公司运转的根本 | 区间，定位季度/半年/年度内的现金变化 |

权责发生制：企业以权利和责任的发生为依据确认收入和费用，不以现金是否收付为准。收入在赚取时确认，费用在发生时确认。

勾稽关系：会计账簿与报表之间数字可相互核对、相互验证的逻辑关系。下面以奶茶店为例，说明三大表关系，单位为万元。

### 月初：资产负债表

```plaintext
 资产负债表：资产 = 负债 + 净资产（股东权益/所有者权益）
【现金20 + 机器/桌椅30 + 奶茶原材料5】 = 【借款25 + 原材料赊账5】+【剩余25】
```

### 当月：利润表

```plaintext
 利润表：收入 - 成本 = 利润
【实收8 + 被赊账2】-【奶茶原材料4 + 房租3】=【净利润3】
```

### 当月：现金流量表

## 三、资产负债表科目

### 1. 资产

#### 流动资产（流动：一年之内要处理）

- 货币资金：现金
- 应收票据：银行承兑 + 商业承兑
- 应收账款：30%以上小心；50%以上 pass

  ```plaintext
  1. 对比营收增速/货币现金增速/应收账款增速，同步增长为正常
  2. 应收账款账龄：一年内账龄占比高较好
  3. 应收/营收，同行业对比，建筑行业通常较高
  ```

- 预付账款：物料费
- 存货：原材料、半成品、库存等

  ```plaintext
  1. 白酒越存越值钱、啤酒过期
  2. 周期股考虑库存跌价风险（金属矿产、存储）
  3. 计价方法：
    - 先进先出FIFO（如果存货涨价，利润虚高；反之，放大亏损）
    - 月末/移动加权平均法（常用）
    - 个别计价法（房地产、珠宝）
  ```

#### 非流动资产

- 长期股权投资：投资其他公司股票等，关注利润表中“投资收益”，警惕利润输送
- 投资性房地产：非生产性投资
- 固定资产：车船、机器设备等

  ```plaintext
  - 折旧：折旧方法，逐年折旧，利润表中折旧费用
  - 减值：一次性减值，如机器报废
  ```

- 在建工程：猫腻较多

  ```plaintext
  - 关注工程进度，注意是否按时转入固定资产，如果未转入，可能存在以下情况：
    1. 美化利润：已建好未转入，则不需要每年折旧
    2. 虚假工程，资金挪用
  ```

- 长期待摊费用：长期租金、装修支出等，逐年分摊，类似折旧
- 递延所得税资产：如暂时多缴的税，以后可以抵扣；与之对应的是负债中的递延所得税负债
- 无形资产：土地使用权、特许经营权、专利权、商标权、著作权、研发费用、利息费用

  ```plaintext
  1. 需要考虑折旧和摊销
  2. 特许经营权：获取经营资格的花费，在一定年限内可以使用
  3. 研发费用（研究阶段 + 开发阶段）
    - 研究阶段：属于利润表，当期消化；有税收优惠，但侵占短期利润
    - 开发阶段：属于无形资产，逐期摊销；可以美化利润表（警惕医药、科技企业）
  ```

- 商誉：超过可辨认资产（净资产）的获利能力

  ```plaintext
  1. 粗略估算：商誉 = 市值 - 净资产
  2. 没有明确期限，不能摊销，只能做减值测试
  3. 只有在收购时才产生，一旦减值，很难回转
  4. 商誉/股东权益，占比超过5%，谨慎；超过10%，pass
  5. 收购要有具体原因和规划
  6. 警惕跨行业收购，最好为上下游产业链
  ```

### 2. 负债

#### 经营性负债（无息负债 positive）

- 应付账款：纯信用赊账，没有正式票据，通常无息

  ```plaintext
  1. 拿到了货，还欠上游的钱
  2. 代表对上游的话语权
  3. 收到货，资产（货物）和负债同步增加
  4. 还钱，资产（钱）和负债同步减少
  ```

- 应付票据：开了银行/商业承兑汇票，有正式票据，可能有利息或保证金

  ```plaintext
  1. 可能暗示话语权不强
  2. 结合应付账款/应付票据比例分析
  ```

- 预收款项/合同负债

  ```plaintext
  1. 收下游钱，暂未发货
  2. 数值越大，对下游话语权越大
  3. 收到钱，资产（钱）和负债同步增加
  4. 交货，资产（货物）和负债减少，股东权益按毛利额变动
  5. 可以预示下季度业绩情况（营业收入增加）
  ```

#### 分配性负债

- 其他应付款 = 应付股利 + 其他

  ```plaintext
  1. 宣告分红时，减少股东权益中的未分配利润
  2. 部分分红发生；部分还未支付的，归到应付股利
  ```

#### 融资性负债（有息负债 negative）

- 短期借款
- 一年内到期负债
- 长期借款

  ```plaintext
  1. 有息负债占总资产的比例：成熟期小于20%，发展期30%
  2. 货币现金/短期有息负债：大于0.75
  3. 短期有息负债/总有息负债：小于30%；大于50% pass
  4. 利率：最好小于3%
  5. 存贷双高
    - 存款、贷款同时高企 -> 可能有问题
    - 叠加（应收/存货高企）-> 大概率有问题
    - 查看利息收入，反推存款流动性/真实性
  ```

### 3. 所有者权益

- 实收资本：注册资本、股本
- 资本公积

  ```plaintext
  1. 股东投入资本产生的溢价
  2. IPO/再融资，通常会大幅增加
  3. 结合资产端和负债端，思考公司规划
  4. 不属于企业经营所得，无法分配
  ```

- 盈余公积：企业赚取的利润，按照规定留下来的一部分钱
- 未分配利润

  ```plaintext
  1. 企业历年赚取的利润，进行分红之后，剩余的部分
  2. 不等于分红money，不等于实际现金流
  3. 可能已经投入再生产
  ```

- 少数股东权益

  ```plaintext
  1. 母公司持股子公司70%，合并财务报表时，完全合并
  2. 子公司净资产中，70%归属于母公司股东
  3. 剩余30%，即为少数股东权益
  ```
